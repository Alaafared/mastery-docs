# وحدات جدارات تخصص الكهرباء

موقع ويب بسيط ومنظم لتصفح وتحميل وحدات جدارات تخصص الكهرباء (الصفوف الثلاثة).

## المميزات
- واجهة عربية كاملة (RTL)
- بحث سريع في أسماء الملفات
- فلترة حسب الصف / التخصص / النوع / الترم
- ترتيب النتائج
- تحديد عدة ملفات وتحميلها
- طباعة القائمة
- روابط مباشرة لجوجل درايف (عرض + تحميل)

## كيفية الاستخدام
1. افتح ملف `index.html` في أي متصفح.
2. أو ارفع المجلد كاملاً على GitHub Pages / Netlify / أي استضافة مجانية.

## ملاحظات
- بعض العناصر روابط لمجلدات كاملة (لأن الملفات كثيرة ومتشعبة).
- يمكن إضافة المزيد من الملفات بسهولة بتعديل ملف `data.js`.
- التحميل يعتمد على صلاحيات المشاركة في جوجل درايف.
